# 松间 · 诗词书房

一个轻量、可离线运行的个人诗词背诵网站。收录诗词、按作者或词牌筛选、逐档挖空背诵，并在日历中回看练习与收录记录。

## 在线体验

部署到 GitHub Pages 后，可直接通过公开网页使用。每位使用者的数据保存在自己当前浏览器的本地存储中；网站不会把诗词或练习记录发送到服务器，也没有账号或云端同步功能。

## 下载后在自己的电脑使用

1. 在 GitHub 项目页选择 **Code → Download ZIP** 并解压。
2. 安装 Python 3（如果电脑尚未安装）。
3. 双击 `start-local.bat`。
4. 浏览器会打开本地书房。关闭启动窗口即可停止本地服务。

也可以运行 `python serve_local.py`，再用浏览器访问 `http://127.0.0.1:8765`。

本地启动方式使用固定的 `localhost` 地址，让浏览器可以稳定保存这份电脑上的独立数据。GitHub Pages 与本地运行的数据彼此分开；要迁移诗词和练习记录，请使用网站右上角的备份与恢复功能。请定期导出备份，并妥善保管。不要把备份文件提交到公开仓库。

## 主要功能

- 手动收录诗词，保留标点与分行；词牌词名和组诗序号可从题目中自动识别。
- 按作者与词牌名筛选诗词集。
- 从 20% 到 100% 连续挖空练习，记录每档完成日期。
- 查看每日背诵诗词数、新收录诗词数和练习记录。
- 为每首诗记录可选诗话。
- 导出、恢复个人数据，并生成只读分享快照。
- 卡片标记已完成 100% 挖空的诗词。

## 数据与隐私

诗词与练习记录储存在浏览器本地存储中。清除网站数据、换浏览器或换电脑时，数据不会自动迁移；请使用备份功能。GitHub Pages 上的每个浏览器用户拥有自己的本地数据副本，同一台设备、同一个浏览器配置文件中的使用者会看到同一份数据。

只读分享网页是生成时的静态快照。请只分享你愿意公开的内容。

## 本地预览与发布

项目是静态网页，不需要数据库服务或构建步骤。GitHub Actions 会在推送到 `main` 分支后自动发布 GitHub Pages。首次发布时，在仓库 **Settings → Pages → Build and deployment** 中将 **Source** 设为 **GitHub Actions**。
